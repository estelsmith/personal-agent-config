# Terminal & Bash Tool Execution Rules

Global execution conventions for terminal command execution. Follow these whenever executing commands.

## Prepending Command Intent as Comments

When executing commands with the `bash` tool, prepend a concise comment at the top explaining the intent, purpose, or hypothesis behind running the command.

- Include a brief explanation at the start of the command (e.g. `# Querying Zuplo API to verify consumer status`) so the user can easily follow why the command is being run.
- Keep the comment clear and focused on the immediate action or rationale.
