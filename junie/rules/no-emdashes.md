# Writing & Formatting Rules

Global style conventions for all written output across repositories.

## Never Use Emdashes

Do not use emdashes (`U+2014`) anywhere in prose, documentation, code comments, commit messages, UI text, or responses to the user.

- **Use standard punctuation instead**: Replace parenthetical or explanatory dashes with commas, colons, semicolons, parentheses, or separate sentences.
- **Do not substitute double hyphens (`--`)**: Avoid using `--` as an ASCII stand-in for an emdash in prose.
